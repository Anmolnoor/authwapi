# Security

AuthWAPI is early: don't put real users on it yet. Security reports are still welcome.

## Reporting a vulnerability

Report it privately through GitHub: the repository's **Security** tab → **Report a vulnerability**
(<https://github.com/Anmolnoor/authwapi/security/advisories/new>). Please don't open a public issue or pull request
for it.

Include what you found, how to reproduce it, and the version or commit. You'll get a reply in the advisory.

## Supported versions

Only the latest release gets fixes.

## Dependencies

A problem in Better Auth or another dependency itself is best reported to that project. If it affects AuthWAPI,
report it here too.
