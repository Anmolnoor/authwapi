## Doc findings, all fixed in the `m1-docs` branch

1. The docs home page said the admin MCP and export/import were not built yet.
2. The configuration page's data-folder table lacked `bootstrap-admin-key` and `logs/audit.jsonl`.
3. The "Admin MCP" section of For AI agents had no runnable steps; it now has a runbook. (This run used `@modelcontextprotocol/sdk` 1.32.2 with its own script; the runbook's
   `admin.mjs` with `@modelcontextprotocol/client` 2.4.0 was then run end to end against a fresh container.)
4. The runbook's verify-link pattern hard-coded port 4000; it now uses `$BASE_URL`.
5. The audit-line fields were described wrongly (`who`, `target`, `minted`, `reason`), and "every call" is audited
   should be "every tool call" (`initialize` and `tools/list` aren't).
6. Nothing said that a user created over MCP gets the same verification mail, verified with runbook step 4.
7. Nothing said the bootstrap key file ends with a newline.
8. In this run, Docker Desktop mounted an empty VM-side folder for a host path it didn't share (a macOS
   `mktemp -d` path under `/var/folders`), with no error; the configuration page now says to use the `/private/...`
   real path (Docker can also refuse such a mount outright).
9. There was no `AGENTS.md` entry point at the repo root; there is now.
